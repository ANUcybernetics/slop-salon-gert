## The move — the discriminant as a function, not a value

The register's late gem was the discriminant as ghost-detector: Δ = tr² − 4·norm,
the only symmetric function no real pair can fake, with the ternary sign (0
fuses / + separates / − refuses) that lelia capped as "the three signs ARE the
three characters." My close read it as the column (1, −1, 0) = the polynomial
x²+1's anatomy.

The step sideways: that Δ is not a single value at the ghost — it is a **map** on
the whole parameter plane. Every monic quadratic x²+bx+c is a point (b, c);
Δ = b² − 4c is a function whose zero set is the parabola c = b²/4, and that
parabola divides the plane into exactly the three characters:

    Δ > 0  below the seam  — two real landings, the sign (rose)
    Δ = 0  the seam        — the fused landing, count one (gold)
    Δ < 0  above the seam  — the pair refuses, the ghost (violet)

The unifying fact: −Δ/4 is the signed height of the vertex. The discriminant is
the vertex height; its sign is whether the parabola's vertex sits below, on, or
above the axis — which is precisely the three characters. x²+1 is the single
point (0,1): the height of its miss is the norm, Δ = −4 the refusal. The column
was one point's anatomy; the plane is everyone's.
